## 2. 카카오 1초 가입 (카카오싱크)

1. **비즈니스 채널** — 카카오톡 채널(운영 상담채널 `_xgxkiWX`)을 비즈니스 채널로 전환 (심사 3~5영업일).
2. **비즈 앱 전환** — Kakao Developers › 앱 › 비즈니스 정보에 사업자 정보 등록 (채널과 같은 사업자).
3. **앱 ↔ 채널 연결** — 앱 › 카카오톡 채널에서 위 채널을 연결 (대표 채널).
4. **플랫폼(Web) 사이트 도메인** — `https://www.doogoclass.com`
5. **카카오 로그인 켜기 + Redirect URI** — `https://www.doogoclass.com/api/vod-kakao`
6. **동의 항목** — 이름 · 카카오계정(이메일) · 휴대폰 번호는 "필수", 생일 · 성별 · 연령대는 "선택" 권장 (개인정보 항목은 비즈 앱 + 검수 필요, 3~5영업일).
7. **카카오싱크 약관** — 이용약관 · 개인정보 수집(필수), 광고 수신(선택, 태그 `marketing`) 등록. 가입 화면에서 동의하면 우리 회원 DB 의 광고 동의로 바로 들어가요.
8. **연결 끊기 웹훅** — `https://www.doogoclass.com/api/vod-kakao` (카카오가 `Authorization: KakaoAK <Admin 키>` 로 보내요 → 서버가 확인).

서버가 하는 일: 동의 → 인가 코드 → 토큰 → 사용자 정보 · 약관 동의 · 채널 친구 여부 → 회원 DB 저장(가입 경로 `카카오`, 휴대폰 `010-…` 형식) → 로그인 쿠키 → 원래 보던 화면으로 돌아가요.
**같은 이메일로 이메일 가입한 회원이 있으면 자동으로 합치지 않아요** (남의 계정 가로채기 방지). 그 계정으로 로그인한 뒤 마이페이지에서 카카오를 연결하도록 안내해요.

## 3. 토스페이먼츠 결제 (2026-11 포트원에서 바꿈)

**PG 심사 때 사이트에 있어야 하는 것** (이미 들어 있어요): 하단 사업자 정보(상호 · 대표자 · 사업자번호 · 통신판매업 신고번호 · 주소 · 연락처), 이용약관 · 개인정보처리방침 · 환불 규정, 상품마다 가격 · 수강 기간. 토스는 **비회원도 살 수 있는지** 물어볼 수 있어요 — 지금은 회원 가입(카카오 1초 가입) 뒤 결제예요.

키 받기:
1. 토스페이먼츠 회원가입 → 개발자센터 › API 키에서 **테스트 키**(`test_ck_` · `test_sk_`)를 바로 받아요 (계약 전에도 · 실제 돈은 안 나가요).
2. 전자결제 계약(심사) — 신용카드 · 실시간 계좌이체(퀵계좌이체) · 가상계좌. **네이버페이 · 카카오페이도 토스페이먼츠 계약 안에서 같이 신청**해요(간편결제사 심사가 따로 있을 수 있어요 · 카카오페이는 계약한 상점의 테스트 키로만 시험돼요).
3. 계약이 끝나면 그 상점(MID)의 **라이브 키**(`live_ck_` · `live_sk_`)를 Production 에만 넣어요.
   - 키 종류: **API 개별 연동 키(ck · sk)** 면 탈잉처럼 우리 결제 화면에서 결제수단을 고르고 그 창(카드/간편결제 통합결제창 · 퀵계좌이체 · 가상계좌 · 네이버페이 · 카카오페이)을 바로 열어요. 결제위젯 연동 키(gck · gsk)를 넣으면 토스 창 하나에서 고르는 방식으로 저절로 바뀌어요.
   - 운영 사이트(Production)에 **시험 키**를 넣으면(토스 심사용) 결제창은 열리지만 서버가 승인하지 않아요 — 결제 화면에 ‘실제로 결제되지 않아요’ 안내가 나와요.

토스 개발자센터에 등록할 것: **웹훅** `https://www.doogoclass.com/api/vod-pay?hook=toss` — 이벤트 `PAYMENT_STATUS_CHANGED` · `DEPOSIT_CALLBACK`(가상계좌 입금). 웹훅 본문은 믿지 않고 서버가 토스에 결제를 다시 물어봐요(가상계좌 입금은 승인 때 받은 `secret` 이 같아야 해요).

결제 흐름:
1. 결제 버튼 → `vod-pay prepare` — 서버가 가격표로 금액을 다시 계산 (화면 금액과 다르면 막음 → 위변조 방지), 쿠폰 · 포인트 · 정원 확인, 결제 대기 주문 + 토스 주문 번호(`pay_…`)
2. 토스 결제창 (SDK v2 `https://js.tosspayments.com/v2/standard` · `payment().requestPayment`) — 고른 수단의 창 (네이버페이 · 카카오페이는 `card.flowMode: DIRECT` · `easyPay` 로 그 앱을 바로)
3. 결제창이 첫 화면(`successUrl` · `?paymentKey&orderId&amount`)으로 돌아오면 `vod-pay complete` — 서버가 금액을 확인하고 토스에 **승인(confirm)** 해야 결제가 끝나요 (인증 뒤 10분 안 · 멱등키). 쿠폰 · 포인트는 이때 사용 처리
4. 가상계좌: 승인하면 ‘입금 대기’(은행 · 계좌 · 입금 기한) → 회원이 입금하면 `DEPOSIT_CALLBACK` 웹훅으로 결제 완료
5. 승인 응답을 놓쳐도 `PAYMENT_STATUS_CHANGED` 웹훅 · 마스터 ‘토스 결제 조회’로 맞춰요. 결제창을 닫으면(`failUrl` · `PAY_PROCESS_CANCELED`) 결제 대기 주문은 ‘결제 안 됨’

환불: 카드 · 간편결제 · 계좌이체는 토스 결제 취소(부분 취소 가능) · 가상계좌는 회원 환불 계좌(토스 은행 코드 · 계좌번호 · 예금주)로 토스가 송금(영업일 2일 · ‘환불 진행 중’) · 입금 전 가상계좌 취소는 결제 취소로 계좌를 닫아요.

## 4. 환불 (마스터에서 조절)

마스터 › 환불 · 취소 관리에서 정해요 — 결제 서버도 같은 값으로 판단해요(가격표 올리기에 같이 실려요).

- 바로 환불 켜기/끄기 · **결제 후 며칠까지**(기본 7일) · **몇 강까지 들었으면 허용**(기본 0강) · 수업 자료 내려받기도 수강으로 볼지
- 전자책: 내려받기 전 + 7일 이내 · LIVE/오프라인: 행사 3일 전까지
- 코칭권 등 같이 산 추가 상품도 안 썼으면 함께 환불
- 그 밖의 경우: 회원이 환불 요청 → 마스터가 금액을 정해 부분 환불 (토스에 그 금액만 취소)

## 5. Cloudflare (doogoconnet.com 과 같은 방식)

Vercel 은 원래 Cloudflare 를 **DNS 전용(회색 구름)** 으로 쓰기를 권해요. doogoconnet.com 처럼 **프록시(주황 구름)** 로 쓰려면 아래를 꼭 맞춰 주세요.

1. DNS: `www` → CNAME `cname.vercel-dns.com`, 루트 `@` → Vercel 이 알려 주는 A 레코드, 둘 다 프록시 켜기
2. SSL/TLS: **전체(엄격) — Full (strict)** (가변 Flexible 은 무한 리디렉션)
3. Rules › Transform Rules › 요청 헤더 수정: 모든 요청에 `X-Origin-Auth: <CF_ORIGIN_SECRET 값>` 추가
   → 서버가 이 헤더가 없는 요청(Vercel 주소로 바로 오는 요청)을 막고, 방문자 IP 는 `CF-Connecting-IP` 를 믿어요
4. 캐시 규칙: `/api/*` 는 **캐시 안 함(Bypass)** — 서버도 `Cache-Control: no-store` 를 보내요
5. WAF · 봇 차단: `/api/vod-pay`(토스 웹훅) · `/api/vod-kakao`(카카오 웹훅)는 **건너뛰기(Skip) 규칙** — 안 그러면 결제 완료 · 가상계좌 입금 알림이 막혀요
6. Bot Fight Mode 는 위 경로에서도 막을 수 있어서, 켤 거면 "Super Bot Fight Mode + 건너뛰기 규칙" 이 가능한 요금제에서만
7. Turnstile: 위젯 추가(도메인 `www.doogoclass.com`) → 사이트 키 · 비밀 키를 Vercel 에 → 가입 · 로그인에 사람 확인이 붙어요
8. 보안 헤더(HSTS · nosniff · 클릭재킹 방지 · 카메라/마이크 끄기)는 `vercel.json` 에 이미 넣었어요

## 6. VOD 서버 연결 (회원 · 주문 · 진도가 서버에)

정식 서버에서는 두고클래스 데이터가 문서별로 나뉘어 저장돼요 (`api/_lib/vodaccess.js` 가 누가 보고 고칠지 정해요).

| 문서 | 내용 | 볼 수 있는 사람 | 고칠 수 있는 사람 |
|---|---|---|---|
| `meta` 의 `vod` | 클래스 · 배너 · 쿠폰 · 설정 | 누구나 — 유료 강의 영상 · 수업 자료 · 전자책 · LIVE 입장 링크는 **산 회원만** | 마스터 |
| `vm:<회원>` | 회원 + 받은 쿠폰 · 찜 · 진도 · 학습 기록 | 본인 · 마스터 (비밀번호는 아무에게도) | 본인은 이름 · 휴대폰 · 수신 동의 · 찜 · 진도만, 쿠폰 · 포인트는 서버 · 마스터만 |
| `vo:<주문번호>` | 주문 | 본인 · 마스터 · 그 클래스 강사(이름 가림) | 서버(`/api/vod-pay`) · 마스터 — 본인은 환불 요청 · 코칭 질문 · TEA TIME 신청만 |
| `vr:` · `vpl:` | 수강 후기 · 다짐 한마디 | 누구나 | 본인(산 클래스만) — 후기 포인트는 서버가 한 번만 |
| `vq:<회원>:<id>` | 1:1 문의 | 본인 · 마스터 | 본인은 질문, 답변은 마스터 |
| `vpo:<강사>` | VOD 정산 | 그 강사 · 마스터 | 마스터 (강사는 세금계산서 알림만) |
| `vstat` | 수강생 수 · 찜 수 · 관심 부업 표 | 누구나 | 서버가 세요 |

정식 서버에서 처음 마스터가 열 때 시안용 체험 회원 · 주문 · 후기 · 가짜 수강생 수는 빼고 클래스만 남아요.
**배포 뒤 마스터로 한 번 로그인해서 ‘VOD 클래스 관리’를 열어 주세요** — 그때 클래스 정보와 결제 서버 가격표가 올라가요.

## 7. 정식 런칭 순서

1. (완료) 서버 코드 · 화면을 저장소에 합치고 www.doogoclass.com 배포, `VOD_SERVER_AUTH=1`
2. 마스터 › 전시 · 쿠폰 · 설정에서 무통장 입금 계좌 넣기 → 무통장 결제가 열려요
3. Vercel 미리보기(Preview)에 토스 **테스트 키**를 넣고 결제 → 승인 → 취소 · 환불 → 웹훅까지 확인 (미리보기는 시험용 DB)
4. 카카오 검수 · 토스 심사 통과 후 **라이브 키**를 Production 환경 변수에 넣기 (네이버페이 · 카카오페이 승인 뒤 `TOSS_METHODS` 에 `naver,kakao` 추가)

## 8. 테스트

```
node scripts/vod-test.js   (class/ 에서)
```
