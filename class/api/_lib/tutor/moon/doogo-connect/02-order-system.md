# 제조 견적 및 의뢰 시스템
(출처: 문대표가 보낸 학습 파일 doogo-connect-prompts/02-order-system.md · 2026-11-03 반영)
두고커넥트는 실제 제조 수요를 걸러 내고 제조사를 보호하려고 포인트 시스템을 운영해요.

## 제조 견적 요청 (5,000P)

- 제조 견적 요청 1건에 5,000P를 써요.
- 무분별한 견적 요청을 막고, 실제로 제조할 의사가 있는 분과 제조사를 이어 드리려는 장치예요.

## 견적 포인트 환불
<!-- 질문: 포인트 환불, 포인트환불, 원료 부족, /(견적|포인트|5000p|5,000p).{0,12}(환불|돌려|반환|취소|안\s*되면|못\s*하면|진행\s*안|진행이\s*안)/i, /(환불|돌려|반환).{0,10}(견적|포인트)/ -->
- 제조사의 원료 부족이나 그 밖의 사유로 견적이 정상적으로 진행되지 않으면, 쓴 5,000P는 전액 환불돼요.
